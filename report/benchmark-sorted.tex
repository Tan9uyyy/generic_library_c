\chapter{Maps for sorted data}\label{chap:maps:sorted}

We benchmarked different binary search tree variants:
\begin{itemize}
    \item **Standard BST:** No balancing guarantees.
    \item **Treaps:** Randomized balancing.
    \item **Splay Trees:** Self-adjusting based on access patterns.
\end{itemize}

**Results:**
Standard BSTs performed well for random data but degraded to $O(N)$ for sorted input. Treaps offered consistent $O(\log N)$ performance regardless of input order. Splay trees excelled in scenarios with high temporal locality but had higher overhead for random access patterns.
