\chapter{Array sorting}\label{chap:sorting}

Sorting is a fundamental operation in computer science. We implemented generic sorting routines for our dynamic arrays.

\section{Design rationale}

We focused on providing a generic sorting interface that works with any data type, using a user-provided comparison function.

We implemented Quicksort as the default sorting algorithm due to its excellent average-case performance ($O(N \log N)$) and in-place nature. For stability (preserving the relative order of equal elements), we also provide Mergesort, which requires additional memory ($O(N)$) but guarantees stability.

\section{Array sorting interface}

The interface provides:
\begin{itemize}
    \item \texttt{array\_sort}: Sorts the array using the default algorithm (Quicksort).
    \item \texttt{array\_stable\_sort}: Sorts the array using a stable algorithm (Mergesort).
\end{itemize}

Both functions take a pointer to the array and a comparison function pointer.
