\chapter{Sorting routines}\label{chap:benchmark:sorting}

We compared our sorting implementations against the standard library's `qsort`.

**Algorithms tested:**
\begin{itemize}
    \item **Quicksort:** Our default unstable sorting routine.
    \item **Mergesort:** Our stable sorting routine.
    \item **Heapsort:** Using our binary heap implementation.
    \item **Standard qsort:** For baseline comparison.
\end{itemize}

**Results:**
Our generic Quicksort implementation was competitive with `qsort`. Mergesort was slower and consumed more memory but correctly maintained stability. Heapsort was generally slower than Quicksort but provided guaranteed $O(N \log N)$ worst-case performance.
