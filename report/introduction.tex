\chapter*{Introduction}\label{chap:introduction}

This report presents the work done for the APMAN project. The goal was to implement a library of abstract data types and data structures in C, following a generic and modular approach. We implemented various linear and non-linear data structures, including dynamic arrays, lists, stacks, queues, deques, maps, hashtables, and trees. We also performed benchmarks to evaluate the performance of our implementations.

The project emphasizes code quality, memory management, and the use of advanced C features like macros and function pointers to achieve genericity and flexibility.
